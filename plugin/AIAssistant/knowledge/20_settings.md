## Частые ключи настроек

| Что | Ключ | По умолчанию / правило |
|---|---|---|
| Профиль качества | `quality_type` | старт: normal (Fine); high (Extra Fine) — для точных профилей и декора |
| Высота слоя | `layer_height` | функциональная деталь 0.2; точный профиль (зубья, кулачок, посадки) 0.1–0.15; декор «без слоёв» 0.1; гибкие (TPU, TPV) 0.2 |
| Высота слоя 5D | `cylindrical_layer_height` | для слоёв, навиваемых вокруг оси |
| Стенки | `wall_line_count` | нагруженная деталь 4–6; зуб шестерни 6+ (зуб целиком из периметров); декор 3; тонкая гибкая стенка (гофра) 2–3 |
| Верх/низ | `top_bottom_thickness` | под винт, в ступице — толще (1.2+ мм) |
| Заполнение | `infill_sparse_density` | нагруженная 50–80 %; 100 % — ступица под винт или шпонку, деталь на балансировку (крыльчатка, насос), герметичность; декор 15–20 % |
| Узор | `infill_pattern` | нагруженная: gyroid или cubic |
| Температуры | `material_print_temperature`, `material_bed_temperature` | брать из профиля материала, не менять без причины |
| Обдув | `cool_fan_speed` | PC, ABS, PA и композиты на них: до 20 %; PP G30: 0–10 % |
| Поддержки | `support_enable`, `support_type`, `support_tree_enable`, `support_interface_enable`, `support_z_distance` | сначала ориентация без нависаний; декор: древовидные только от стола, интерфейс, зазор Z ~0.2 |
| Адгезия | `adhesion_type` | PC, PA, ABS и композиты, тонкие кромки → brim; PETG и декор → skirt (brim оставит след) |
| «Слоновья нога» | `xy_offset_layer_0` | шестерни и точный низ: −0.1…−0.15 мм |
| Размер отверстий | `xy_offset` | отдельной компенсации отверстий нет; xy_offset меняет весь контур. Отверстие ±0.1 мм — честно советуй развёртку после печати |
| Шов | `z_seam_type`, `z_seam_x`, `z_seam_y` | убирать шов с рабочих поверхностей (кулачок, протектор) |
| Скорость | `speed_print` | TPU 20–25 мм/с; герметичная гибкая деталь 15–20 мм/с |
| Поток | `material_flow` | герметичная гибкая стенка ~105 % |
| Ретракт | `retraction_amount`, `retraction_combing` | гибкие: короткий ретракт, combing внутри детали (`all`); PC+стекло: ~0.8 мм |

## Подбор по требованиям

- Точность (зубья, кулачки, посадки): тонкий слой, медленные внешние стенки, точный профиль в плоскости слоя
  (3D) или на поверхности навивки (5D).
- Нагрузка: прочность дают в основном стенки, а не заполнение. Выше 80 % прочность почти не растёт, а время растёт.
- Герметичность: сплошная стенка (100 %), медленно, без ретрактов внутри детали.
- Без видимых слоёв: слой 0.1, ориентация так, чтобы поддержки были на невидимой стороне.
- Партия из N штук: проверь, помещаются ли копии на стол; если нет — скажи, сколько влезает за раз.
- В «Компромиссах» напоминай про сушку гигроскопичных материалов (см. материалы).

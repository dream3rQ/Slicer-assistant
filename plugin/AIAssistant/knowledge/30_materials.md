## Как переводить ТЗ в требования recommend_materials

| В ТЗ написано | Ключ |
|---|---|
| гидрофобный, не впитывает влагу, влажность 85–98 % | max_water_24h_pct: 0.1 |
| водопоглощение не более X % | max_water_24h_pct: X |
| прямое солнце, УФ, не желтеет | min_uv: 2 |
| озон | min_ozone: 2 |
| нагрев до T °C, не размягчается при T | min_heat_c: T |
| Tg не ниже T | min_tg_c: T |
| Вика не ниже T | min_heat_c: T |
| модуль упругости не менее X МПа, зуб не подгибается | min_modulus_mpa: X (без числа: 3000) |
| удлинение не менее X % | min_elongation_pct: X |
| плотность не более X, «максимально лёгкий» | max_density: X |
| без хрупкого разрушения, без осколков, удары | min_toughness: 2 |
| масла, СОЖ, смазка, бензин, дизель | min_oil_fuel: 2 |
| щёлочь, pH > 9, щелочная мойка | min_alkali: 2 |
| кислоты, подкормки | min_acid: 1 (сильные — 2) |
| спирт, IPA, спиртовые салфетки | min_alcohol: 1 |
| абразив, износ, трение скольжения | min_wear: 2 |
| эластичный, гибкий, пыльник, уплотнение | flexible: true |
| высокий коэффициент трения, не проскальзывает | friction: high |
| низкий коэффициент трения, без смазки | friction: low |
| диэлектрик, без токопроводящих наполнителей | no_conductive_filler: true |
| антистатик, ESD | antistatic: true |
| пищевой контакт, не токсичен | food_contact: true |
| не видно слоёв, декоративная поверхность | smooth_surface: true |

Если в ТЗ про жёсткость/гибкость ничего нет, инструмент считает деталь жёсткой.
Свойства в таблице оценочные: если два кандидата близки, выбирай тот, что прямо назван
в description материала для такого применения.

## Правила выбора
- Жёсткие числа ТЗ (водопоглощение, Tg, Вика, модуль, плотность, проводимость) отсекают материал,
  если он не проходит хотя бы одно. Остальное — ранжирование.
- Если ТЗ противоречит таблице (например, «пищевая зона», а подходящий по механике материал
  не пищевой), прямо скажи об этом пользователю, а не выбирай молча.
- Сушить перед печатью: все PA (PA6, PA12 G12, ABS/PA G8), PC, PC G20, PETG, все TPU.
- Капризные на столе: PP и PP G30 (плохо липнут, нужен PP-скотч или PP-основание), PC и ABS (коробит),
  TPV 80 (PP-скотч).
- Горячая щелочная среда (+85 °C, pH 10): PC и PET разрушаются (гидролиз), подходят PP, PP G30, TPV.
